# Restore Britain's Churches

Official project repository for the proposed **Restore Britain's Churches** church-history documentary and restoration initiative.

## Proposed public address
`restore.remoteability.org.uk` — DNS and hosting have **not** been configured yet.

## Current deployment stage
This repository currently contains a **static preview landing page** at `index.html` suitable for GitHub Pages. This first online-compatible version does not yet collect volunteer applications, church nominations or donations.

The separate complete prototype bundle includes a Node.js server, administration page and forms. Those dynamic functions cannot execute on GitHub Pages and need a backend or approved external service before public use.
